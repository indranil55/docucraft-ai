## Reporting a Vulnerability

If you discover a security vulnerability within **DocuCraft AI Studio**, please report it responsibly. 

* **Where to report:** You can report vulnerabilities directly by opening a private security advisory or by contacting the repository maintainer through GitHub.
* **What to expect:** 
  * You will receive an initial response acknowledging your report within 48 hours.
  * We will keep you informed about the progress towards a fix and planned release date.
  * If the vulnerability is accepted, a security patch or update will be published promptly.
